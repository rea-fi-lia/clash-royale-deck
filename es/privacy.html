Política de privacidad

Última actualización: 12 de junio de 2026

Información que recopilamos

Al iniciar sesión recibimos información básica de la cuenta (nombre visible, dirección de correo, imagen de perfil) de Google o proveedores similares. Si registras opcionalmente tu etiqueta de jugador de Clash Royale, obtenemos tu historial de batallas (composición de mazos rivales, resultados, etc.) desde la API pública. Si haces una donación, conservamos el registro de importes que nos comunica el proveedor de pagos (Stripe). Nunca almacenamos datos de pago como el número de tarjeta.

Cómo la usamos

Usamos la información recopilada para ofrecer funciones como guardar mazos y mostrar el meta de enfrentamientos, para mejorar el sitio y para estadísticas que no identifican a personas (por ejemplo, tendencias agregadas de uso de mazos por franja de trofeos). Las estadísticas nunca incluyen nombres, etiquetas, correos ni otra información personal.

Almacenamiento y servicios de terceros

Para el almacenamiento usamos Google Firebase (autenticación y base de datos), para los pagos Stripe y para los datos de batalla el proxy de RoyaleAPI. Para conocer el uso del sitio (páginas vistas, etc.) usamos Google Analytics (GA4), que recopila datos de acceso anónimos mediante cookies. Para la publicidad usamos Google AdSense, que muestra y optimiza anuncios mediante cookies. A cada servicio se le aplica su propia política de privacidad. El localStorage del navegador se usa para guardar ajustes (idioma, favoritos, etc.).

Solicitudes de eliminación

Si deseas eliminar los datos vinculados a tu cuenta, contáctanos a través de Contacto. Lo comprobaremos y los eliminaremos.

Modificaciones

Esta política puede revisarse cuando sea necesario. Si hay cambios importantes, lo anunciaremos en el sitio.
